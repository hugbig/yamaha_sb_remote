# Security policy

## Supported versions

Only the [latest release](../../releases/latest) receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub private vulnerability reporting](../../security/advisories/new).

Include the affected version, a description of the problem and, if possible, steps to reproduce.
You should get an answer within a week. This is a hobby project maintained in spare time, so a fix
may take longer.

## Scope

The integration talks to the soundbar over Bluetooth Low Energy, through Home Assistant's Bluetooth
stack. Issues in the soundbar firmware, Home Assistant or ESPHome should be reported to Yamaha,
Home Assistant or ESPHome.
